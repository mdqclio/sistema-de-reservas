## Qué técnica se eligió y por qué

El SVG tiene un solo `<g fill="currentColor">` con dos paths (casa + delfín).

- `<img src="logo-puerto-delfin.svg">`: **descartado**. Dentro de un `<img>` el SVG es un documento
  aparte; `currentColor` no hereda y cae al color inicial → **negro**.
- `<object>`: mismo problema (documento aparte, no hereda `color`).
- SVG inline copiado en cada página: funciona, pero duplica ~15 KB (incluye el manifiesto C2PA) en
  dos archivos y el logo del repo dejaría de ser la fuente.
- **Elegido: `<svg viewBox="0 0 1176 896"><use href="logo-puerto-delfin.svg#logo"></use></svg>`.**
  Usa el archivo del repo (sin base64, sin copiar paths) y el contenido referenciado por `<use>`
  **sí hereda `color`** del CSS → `color: #6B7C8C`. Es vectorial, así que imprime nítido.
  - Requirió **un solo cambio en el SVG**: `id="logo"` en el `<g>` (validado: el XML parsea y el id
    existe). Nada más del archivo cambió; el PNG no se tocó.
  - Es same-origin (ambos en `/docs` de GitHub Pages), soportado por Safari/iOS, Chrome y Firefox.
  - Limitación: abriendo el HTML como `file://` en Chrome el `<use>` externo no carga (restricción
    de origen de Chrome). En el sitio publicado no aplica.

CSS (igual en las dos páginas):
```css
.brand-logo { display: block; height: 64px; width: 84px; margin: 0 auto 12px; color: #6B7C8C; }
@media (max-width: 360px) { .brand-logo { height: 52px; width: 68px; } }
@media print { .brand-logo { height: 48px; width: 63px; margin-bottom: 8px; } }
```
- Ancho explícito = alto × 1176/896 (proporción del viewBox). No se usó `width:auto` en `<svg>`
  porque en Safari no siempre respeta la proporción.
- **Impresión**: 48px de alto, no queda gigante; el `.header` no se corta (el voucher ya tenía
  `break-inside: avoid` en las tarjetas). El SVG es vector y el color va por `fill`, no por
  background, así que sale aunque "imprimir fondos" esté apagado.
- **Mobile**: 64px, y 52px en pantallas de ≤360px.
- En `checkin.html` (fondo oscuro) el gris #6B7C8C queda con contraste moderado; si se ve apagado,
  se puede aclarar solo en esa página cambiando `color`.
